Flow-Rate Optimization of a Gas Station Fuel Pump System주유소 펌프 시스템의 유속 최적화를 통한 전력 절감

01요약02배경03이론04시스템 모델링05계산·코드06결과07결론08한계09트러블슈팅10재현 방법

지하유류탱크(UST)에서 디스펜서 4대로 휘발유를 보내는 주유소 배관을 Complex Piping System으로 모델링하고, 일반화된 베르누이 방정식(GBE)과 Fanning 마찰계수로 유속별 펌프 전력을 계산했습니다. 이 계산을 엑셀 계산기와 유속 스윕 데이터로 만든 뒤, 시간대별 혼잡도를 입력받아 주유시간과 전력의 가중 비용을 최소화하는 노즐 유속을 출력하는 다층 퍼셉트론(MLP)을 학습시켜, 시간대별 펌프 제어에 따른 연간 전력비 절감액을 산정했습니다. (숭실대학교 화공유체역학 팀 프로젝트, 4인, 2026.05 – 2026.06)

01프로젝트 요약

질문. 주유소 펌프는 하루 종일 같은 유속으로 운전된다. 손님이 적은 시간대에 유속을 낮추면 주유시간은 늘지만 마찰손실이 줄어 전력이 크게 줄어든다. 그렇다면 시간대마다 어떤 유속이 최적이고, 그로 인해 1년에 얼마를 아낄 수 있는가?

접근.

  1. 물리 모델 — 실제 주유소 도면을 참고해 UST → STP 펌프 → 매설관(2″) → 디스펜서·노즐(17 mm) 배관망을 노드·구간으로 나누고, 구간마다 Reynolds 수 → Fanning 마찰계수 → 마찰손실을 구한 뒤 기계적 에너지 수지로 펌프 일과 전력을 계산했습니다.
  2. 데이터 생성 — 이 계산을 수식 기반 엑셀 계산기로 만들고, 노즐 유속 0.05 – 2.40 m/s를 0.05 간격으로 훑는 유속–전력 스윕 테이블(48점)을 생성했습니다.
  3. 최적화 + 머신러닝 — 주유시간과 전력을 0 – 1로 정규화한 가중합 비용함수를 정의하고, 가중치 w별 최적 유속을 학습 데이터로 만들어 MLP(1–50–50–1)를 학습시켰습니다. 서울 동작구 주유소의 시간대별 매출 건수 비율을 w로 변환해 시간대별 최적 유속을 추론했습니다.
  4. 경제성 — 시간대별 전력 절감량 × 운영시간 × 시간대별 전기요금으로 월·연간 절감액을 계산하고 전국 주유소 수로 확장했습니다.

02배경과 문제 정의

국제 유가와 전기요금이 함께 오르면서 주유소의 운영비 절감 수요가 커지고 있습니다. 주유소의 지하탱크 펌프(STP, Submersible Turbine Pump)는 보통 정속으로 운전되어, 손님이 거의 없는 새벽·심야에도 피크 시간과 같은 유량을 밀어냅니다.

유체역학적으로 보면 펌프가 해야 하는 일은 (1) 유체를 들어 올리는 위치수두, (2) 배관 벽면의 마찰손실, (3) 관 부속의 부차손실, (4) 출구의 속도수두의 합입니다. 이 중 위치수두는 유속과 무관한 고정 성분이지만, 마찰·부차손실·속도수두는 유속에 따라 급격히 커집니다. 따라서 유속을 조절하면 전력을 줄일 수 있지만, 유속이 낮아질수록 주유시간이 늘어 고객 대기와 주유소 회전율에 불리합니다.

즉 이 문제는 주유시간과 펌프 전력 사이의 Trade-off이며, 시간대마다 혼잡도가 다르므로 최적점도 시간대마다 다릅니다. 본 프로젝트는 이 Trade-off를 정량화하고 시간대별 최적 유속을 찾는 것을 목표로 했습니다.

03이론적 배경

3.1 일반화된 베르누이 방정식 (GBE, 기계적 에너지 수지)

정상상태 비압축성 유동에서 두 지점 1 → 2 사이의 단위 질량당 기계적 에너지 수지는 다음과 같습니다.

Δ(u²/2) + g·Δz + Δp/ρ + Ws + ℱ = 0   [J/kg]

여기서 Ws는 유체가 외부에 한 축일(펌프가 유체에 일을 하면 음수), ℱ는 마찰 등으로 열에너지로 소산된 비가역 손실입니다. 펌프가 유체에 해야 하는 일을 wpump = −Ws로 두면,

wpump = Δ(u²/2) + g·Δz + Δp/ρ + ℱmajor + ℱminor

본 시스템은 탱크가 통기관(vent)으로 대기와 연결되어 있고 토출부(차량 주유구)도 대기압이므로 Δp/ρ = 0입니다. 탱크 액면의 유속은 0으로 봅니다.

면접 포인트: 베르누이 방정식은 이상유체·무손실 가정이지만, GBE는 여기에 펌프 일(Ws)과 마찰손실(ℱ)을 더해 실제 공정 배관에 쓸 수 있게 확장한 열역학 제1법칙의 기계적 에너지 형태입니다.

3.2 Reynolds 수와 유동 영역

Re = ρ·u·D / μ = (관성력) / (점성력)
영역Re 범위특징마찰계수
층류Re < 2,100유선이 평행, 포물선 속도분포fF = 16/Re (해석해)
천이2,100 – 4,000층류·난류가 번갈아 나타남불확실 (본 프로젝트는 난류식 적용)
난류Re > 4,000와류에 의한 혼합, 평평한 속도분포Re와 ε/D의 함수 (실험식)

현재 노즐 조건(u = 2.385 m/s, D = 17 mm)에서 Re = 702 × 2.385 × 0.017 / 0.0006 ≈ 47,440으로 완전 난류입니다.

3.3 Fanning 마찰계수와 마찰손실

원관 내 유동의 운동량 수지에서 벽면 전단응력 τw와 압력강하의 관계를 얻고, τw를 운동에너지로 무차원화한 것이 Fanning 마찰계수입니다.

fF = τw / (½ ρ um²)   →   ℱmajor = 2 fF um² (L / D)  =  32 fF V̇² L / (π² D⁵)

오른쪽 형태는 u = 4V̇/(πD²)를 대입한 것으로, 같은 유량에서 마찰손실이 D⁵에 반비례함을 보여줍니다. 매설관(2″)과 노즐(17 mm)의 직경비가 약 3이므로 같은 유량에서 마찰손실은 약 3⁵ ≈ 240배 차이가 납니다. 이것이 손실이 노즐 구간에 몰리는 이유입니다.

Darcy 마찰계수와의 관계: fD = 4 fF. 교재(Wilkes)는 Fanning을 쓰므로 모든 계산을 Fanning으로 통일했습니다. (09 트러블슈팅 참고)

난류 마찰계수 식

Colebrook–White: 1/√fF = −4.0 log₁₀( ε/D + 4.67/(Re√fF) ) + 2.28

Colebrook 식은 f가 양변에 있어 반복 계산이 필요하므로, 엑셀 셀 하나로 계산할 수 있는 Shacham 양함수식을 사용했습니다.

fF = { −1.737 ln[ 0.269 ε/D − (2.185/Re) · ln( 0.269 ε/D + 14.5/Re ) ] }−2

HDPE 관(ε = 0.0015 mm)은 ε/D가 10⁻⁵ 수준이라 거의 매끈한 관(hydraulically smooth)에 해당하며, Shacham 결과(노즐 0.00539)는 Moody 차트 판독값(0.0057) 및 Blasius 식 fF = 0.0790 Re−1/4(0.00535)과 잘 일치합니다.

3.4 부차손실 — 급축소 (Sudden Contraction)

단면이 갑자기 좁아지면 유선이 따라가지 못해 vena contracta(축류)가 생기고, 그 뒤 재확대 과정에서 와류로 에너지가 손실됩니다. 손실은 하류(좁은 쪽) 속도수두에 비례합니다.

ℱcontraction = Kc · u2² / 2 ,    Kc ≈ 0.4 – 0.5  (면적비 A2/A1 → 0일수록 0.5에 접근)

2″(A1 = 2.027×10⁻³ m²) → 17 mm(A2 = 2.270×10⁻⁴ m²)의 면적비는 0.11로 매우 작아, 교재 표의 상한에 해당하는 Kc = 0.5를 적용했습니다.

3.5 Complex Piping System (분기 배관망) 해석

하나의 펌프에서 나온 유체가 여러 구간으로 갈라지는 배관망은 다음 세 종류의 식을 미지수 수만큼 세워 연립으로 풉니다.

  1. 노드의 연속식 (질량 보존) — 비압축성 유체이므로 노드로 들어온 유량 = 나간 유량. 예: V̇A = V̇B + V̇C
  2. 구간마다의 에너지 수지 — 노드 i → j 직관 구간에서 g(zj−zi) + (pj−pi)/ρ + 32 fF V̇² L/(π² D⁵) = 0
  3. 펌프 특성식 — 원심펌프의 head–discharge 곡선 Δp = a − bV̇²

본 시스템은 노즐 유량이 측정값으로 고정되어 있으므로, 연속식으로 각 구간 유량을 먼저 확정하고(유량배수) 가장 먼 경로에 대해 에너지 수지를 적용해 필요한 펌프 일을 구하는 방식으로 단순화했습니다.

3.6 펌프 동력과 효율, 가변속 운전

ṁ = ρ V̇total,    Pfluid = ṁ · wpump,    Ppump = Pfluid / η,    H = wpump / g

유속(유량)을 실제로 바꾸려면 밸브로 조이는 방식(throttling)이 아니라 인버터(VFD)로 펌프 회전수를 바꾸는 가변속 운전이 필요합니다. 밸브 조절은 펌프가 만든 압력을 밸브에서 다시 손실로 버리므로 전력 절감 효과가 작습니다. 원심펌프의 상사법칙(Affinity laws)은 다음과 같습니다.

V̇ ∝ N,    H ∝ N²,    P ∝ N³

회전수를 20% 낮추면 동력은 이론상 약 49% 줄어듭니다(0.8³ = 0.512). 본 프로젝트의 "펌프 압력(양정) 조절"은 이 가변속 운전을 전제로 합니다.

3.7 다목적 최적화 — 가중합 스칼라화

주유시간 T(작을수록 좋음)와 전력 P(작을수록 좋음)는 서로 반대 방향으로 움직이므로 하나의 해가 둘을 동시에 최소화할 수 없습니다. 두 목적을 하나의 스칼라 비용으로 묶는 가중합(weighted sum) 방법을 사용했습니다.

T̂ = (T − Tmin)/(Tmax − Tmin),   P̂ = (P − Pmin)/(Pmax − Pmin)
J(u; w) = w · T̂(u) + (1 − w) · P̂(u),    uopt(w) = argminu J
  • 정규화가 필요한 이유 — T는 수백 초, P는 수백 와트로 단위와 크기가 달라, 정규화 없이 더하면 숫자가 큰 쪽이 비용을 지배합니다.
  • w의 의미 — w → 1이면 시간 우선(혼잡 시간대), w → 0이면 전력 우선(한산 시간대). w를 0 → 1로 바꾸며 얻은 uopt들은 시간–전력 Pareto 전선 위의 점들입니다.

3.8 다층 퍼셉트론 (MLP, Multi-Layer Perceptron)

구조와 순전파

MLP는 입력층–은닉층–출력층이 완전연결(fully connected)된 인공신경망입니다. 각 층은 이전 층 출력에 가중치 행렬을 곱하고 편향을 더한 뒤 비선형 활성화 함수를 통과시킵니다.

h⁽¹⁾ = ReLU(W⁽¹⁾x + b⁽¹⁾),   h⁽²⁾ = ReLU(W⁽²⁾h⁽¹⁾ + b⁽²⁾),   ŷ = W⁽³⁾h⁽²⁾ + b⁽³⁾

입력층1혼잡도 가중치 wtime (MinMax 스케일)—

활성화 함수 ReLU

ReLU(z) = max(0, z)

은닉층에 비선형 함수가 없으면 층을 아무리 쌓아도 전체가 하나의 선형 변환이 됩니다. ReLU는 계산이 간단하고 양수 구간의 기울기가 1이라 깊은 망에서도 기울기 소실이 적습니다. ReLU 망은 입력 공간을 여러 구간으로 나눈 구간별 선형 함수를 표현하므로, 본 문제처럼 w에 따라 계단 모양으로 바뀌는 최적 유속을 매끄럽게 근사하는 데 적합합니다.

학습: 손실함수, 역전파, Adam

L = (1/N) Σ ( ŷi − yi )²   (MSE, 회귀)   →   θ ← θ − α · ∂L/∂θ
  • 역전파(Backpropagation) — 출력 오차를 연쇄법칙으로 각 층에 거꾸로 전달해 모든 가중치의 기울기 ∂L/∂θ를 한 번에 계산합니다.
  • Adam 옵티마이저 — 기울기의 1차 모멘트(평균, 관성)와 2차 모멘트(분산)를 지수이동평균으로 추적해 파라미터마다 학습률을 자동 조정합니다. 작은 데이터·적은 하이퍼파라미터 튜닝으로도 안정적으로 수렴합니다.
  • 입력 정규화(MinMaxScaler) — 입력을 0 – 1로 맞춰 경사하강의 수렴을 돕습니다.
  • 종료 조건 — max_iter = 5000, tol = 1e-5(손실 개선이 이보다 작으면 조기 종료), random_state = 42(가중치 초기화 재현성).

왜 MLP를 썼는가

가중합 최적화는 스윕 테이블의 이산 격자(0.05 m/s 간격) 위에서만 답을 주고, w도 0.05 간격으로만 계산됩니다. MLP는 이 (w, uopt) 쌍을 학습해 임의의 w에 대한 연속적인 uopt를 즉시 추론하는 대리 모델(surrogate model) 역할을 합니다. 또한 입력을 날씨·요일·대기 차량 수·실시간 전기요금 등으로 확장하면 같은 구조로 다변수 제어기로 발전시킬 수 있습니다. (한계는 08 참고)

5.4 MLP 최적화 코드 (Python, Google Colab)

핵심 단계는 (1) 주유시간 제약으로 최소 유속 산출, (2) 정규화, (3) w별 argmin으로 학습 데이터 생성, (4) MLP 학습, (5) 시간대별 추론 + 운전 규칙 적용, (6) 절감액 계산입니다.

단계내용
주유시간 제약50 L 차량을 10분(600 s) 내 주유 → Qmin = 0.05/600 = 8.33×10⁻⁵ m³/s → umin = Qmin/An = 0.367 m/s. 이보다 느린 스윕 행은 제외
학습 데이터w = 0, 0.05, …, 1.00 (21개)마다 J = wT̂ + (1−w)P̂의 argmin 유속을 정답으로 사용
시간대 가중치서울 동작구 주유소 시간대별 매출 건수 비율(소상공인365)을 Min-Max 정규화, 극단값 0/1은 0.01/0.99로 보정
운전 규칙w ≥ 0.95(피크)이면 현재 유속 유지, 예측이 현재 유속 이상이면 현재 유속 유지, 데이터 범위로 클리핑
절감액월간 절감 = ΔP[kW] × 운영시간[h] × 30일 × 시간대 전기요금[원/kWh]
import numpy as np
import pandas as pd
from sklearn.neural_network import MLPRegressor
from sklearn.preprocessing import MinMaxScaler
from google.colab import files
import warnings
warnings.filterwarnings('ignore')

# ── 엑셀 업로드 ───────────────────────────────────────────
print('엑셀 파일을 업로드하세요 (주유소_펌프전력_유속스윕.xlsx)')
uploaded = files.upload()
excel_name = list(uploaded.keys())[0]

# ── 고정 파라미터 ─────────────────────────────────────────
D_n       = 0.017               # m  노즐 내경 (17 mm)
A_n       = np.pi * D_n**2 / 4  # m² 노즐 단면적
V_tank    = 0.05                # m³ 차량 연료탱크 (50 L)
T_LIMIT   = 600                 # s  주유시간 제약 (10분)
v_current = 2.385               # m/s 현재 측정 유속
PEAK_THRESHOLD = 0.95           # 혼잡도 이 이상이면 피크 → 현재 유속 유지

# ── 시간 제약 → 최소 노즐 유속 ───────────────────────────
Q_min = V_tank / T_LIMIT
u_min = Q_min / A_n
print(f'\n주유시간 제약: 50L / {T_LIMIT}s ({T_LIMIT//60}분)  →  최소 노즐 유속 = {u_min:.4f} m/s')

# ── 엑셀 '유속 스윕' 시트 로드 ───────────────────────────
df_raw = pd.read_excel(excel_name, sheet_name='유속 스윕', header=0)
df_fluid = pd.DataFrame({
    'velocity': df_raw['노즐유속 u_n'].astype(float),
    'power_P':  df_raw['P (W)'].astype(float),
})
df_fluid['time_T'] = V_tank / (df_fluid['velocity'] * A_n)   # 노즐 1개 기준 주유시간
df_fluid = df_fluid[df_fluid['velocity'] >= u_min].sort_values('velocity').reset_index(drop=True)

# 보간용 배열 (오름차순 필수)
vv = df_fluid['velocity'].values
pp = df_fluid['power_P'].values

# ── 정규화 (0~1 스케일) ───────────────────────────────────
df_fluid['P_norm'] = (df_fluid['power_P'] - df_fluid['power_P'].min()) / \
                     (df_fluid['power_P'].max() - df_fluid['power_P'].min())
df_fluid['T_norm'] = (df_fluid['time_T'] - df_fluid['time_T'].min()) / \
                     (df_fluid['time_T'].max() - df_fluid['time_T'].min())

print(f'제약 적용 후 데이터: {len(df_fluid)}개  |  '
      f'유속 {df_fluid["velocity"].min():.3f}~{df_fluid["velocity"].max():.3f} m/s  |  '
      f'전력 {df_fluid["power_P"].min():.2f}~{df_fluid["power_P"].max():.2f} W')

# ── MLP 훈련 데이터 생성 (정규화 가중합) ─────────────────
X_train, y_train = [], []
for w_time in np.arange(0.0, 1.05, 0.05):
    cost = w_time * df_fluid['T_norm'] + (1 - w_time) * df_fluid['P_norm']
    best_v = df_fluid.loc[cost.idxmin(), 'velocity']
    X_train.append([w_time])
    y_train.append(best_v)
X_train = np.array(X_train); y_train = np.array(y_train)

scaler_X = MinMaxScaler()
X_train_scaled = scaler_X.fit_transform(X_train)

# ── MLP 학습 ──────────────────────────────────────────────
mlp = MLPRegressor(hidden_layer_sizes=(50, 50), activation='relu',
                   solver='adam', max_iter=5000, random_state=42, tol=1e-5)
mlp.fit(X_train_scaled, y_train)
print(f'\nMLP 학습 완료  |  R² = {mlp.score(X_train_scaled, y_train):.4f}')

# ── 시간대별 시나리오 ─────────────────────────────────────
# w_time: 동작구 매출건수비율 Min-Max 정규화 (극단값 0/1 → 0.01/0.99 보정)
# 건수비율(%): 새벽9.9 / 오전18.8 / 낮13.6 / 피크29.0 / 저녁23.9 / 심야4.7
# [혼잡도 w_time, 전기단가(원/kWh), 운영시간(h)]
real_scenarios = {
    '05~09시 (새벽한산)': [0.21,  80, 4],
    '09~12시 (오전평시)': [0.58, 130, 3],
    '12~14시 (낮)':       [0.37, 130, 2],
    '14~18시 (오후피크)': [0.99, 190, 4],
    '18~23시 (저녁)':     [0.79, 130, 5],
    '23~05시 (심야정체)': [0.01,  80, 6],
}
v_min_data = df_fluid['velocity'].min()
v_max_data = df_fluid['velocity'].max()

# 현재 유속 전력 — 선형 보간
P_cur = np.interp(v_current, vv, pp)

# ── AI 추론 + 제약 클리핑 ─────────────────────────────────
print('\n' + '=' * 72)
print(f'  동작구 시간대별 AI 최적 제어 유속  (제약: 주유시간 ≤ {T_LIMIT}s)')
print('=' * 72)
results = []
for slot, (w_time, price, dur_h) in real_scenarios.items():
    pred_v = mlp.predict(scaler_X.transform([[w_time]]))[0]
    pred_v = np.clip(pred_v, v_min_data, v_max_data)
    if w_time >= PEAK_THRESHOLD:
        pred_v = v_current; status = '현재 유지 (피크-속도우선)'
    elif pred_v >= v_current:
        pred_v = v_current; status = '현재 유지 (이미 최적)'
    else:
        status = f'▼ {v_current - pred_v:.3f} 감소'

    P_opt = np.interp(pred_v, vv, pp)
    T_opt = V_tank / (pred_v * A_n)
    dP    = P_cur - P_opt
    monthly = (dP / 1000) * dur_h * 30 * price
    results.append({'slot': slot, 'pred_v': pred_v, 'P_opt': P_opt,
                    'T_opt': T_opt, 'dP': dP, 'monthly': monthly, 'status': status})
    print(f'\n[{slot}]  혼잡도 {w_time:.2f} | 단가 {price}원')
    print(f'  AI 제어 유속 : {pred_v:.3f} m/s  ({status})')
    print(f'  주유시간     : {T_opt:.1f}s  ({"OK" if T_opt <= T_LIMIT else "초과!"})')
    print(f'  펌프 전력    : {P_opt:.2f}W (현재 {P_cur:.2f}W, 절감 {dP:.2f}W)')
    print(f'  월간 절감액  : {monthly:,.0f}원')

# ── 요약 테이블 + 경제성 ──────────────────────────────────
df_result = pd.DataFrame([{
    '시간대': r['slot'], '제어유속(m/s)': round(r['pred_v'], 3),
    '주유시간(s)': round(r['T_opt'], 1), '펌프전력(W)': round(r['P_opt'], 2),
    '전력절감(W)': round(r['dP'], 2), '월간절감(원)': round(r['monthly']),
    '비고': r['status'],
} for r in results])
print('\n' + '=' * 72)
print(df_result.to_string(index=False))
total_m = sum(r['monthly'] for r in results); annual = total_m * 12
print(f'\n  월간 총 절감액 (1개소)        : {total_m:>10,.0f} 원')
print(f'  연간 총 절감액 (1개소)        : {annual:>10,.0f} 원')
print(f'  전국 연간 절감액 (×10,489개) : {annual*10489/1e8:>10,.1f} 억원')

07결론

  1. 주유소 펌프 전력의 대부분은 노즐 구간의 마찰손실이다. 2″ 매설관과 17 mm 노즐의 D⁵ 차이 때문에 펌프 일의 약 84%가 노즐·호스 구간에서 소산되며, 위치수두(1.1 m)는 9% 수준입니다. 따라서 유속 조절의 효과가 큽니다.
  2. 전력만 최소화하면 운영이 불가능하다. 층류 최대 유속은 전력을 96% 줄이지만 주유시간이 35분이 됩니다. 시간–전력 가중 비용과 10분 주유시간 제약을 함께 둔 최적화가 필요했습니다.
  3. MLP 제어로 월 펌프 전력비를 41% 절감했다. 혼잡도에 따라 0.40 – 2.385 m/s로 유속을 바꾸면 1개소 기준 연 약 19.8만원, 전국 확장 시 연 약 20.8억원 규모의 전력비를 절감할 수 있습니다.
  4. 단일 매장의 절감액은 작고, 가치는 규모에서 나온다. 가변속 펌프(VFD) 교체 비용을 고려하면 1개소 단독 투자 회수는 어렵고, 프랜차이즈 단위 일괄 적용이나 신설·교체 시점 도입이 현실적입니다.
