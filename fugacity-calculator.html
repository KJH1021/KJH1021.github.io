Fugacity 계산기

순수 성분: ① Lee/Kesler ② Abbott ③ 포화액체 기준 압축액체 · 2성분 혼합물: 비리얼 식

입력

Psat·Vc·Zc는 압축액체(포화액체 기준) 계산에만 쓰이며, 비워 두면 기체 계산 두 가지만 표시됩니다.

사용한 식

Abbott: B⁰ = 0.083 − 0.422/Tr1.6, B¹ = 0.139 − 0.172/Tr4.2, φ = exp[(B⁰ + ωB¹)·Pr/Tr], f = φP
Lee/Kesler: φ = φ⁰·(φ¹)ω, f = φP. 표를 보간하는 대신 표를 만드는 데 쓰인 Lee-Kesler 상태방정식(단순유체 + 기준유체 n-octane, ωr=0.3978)을 직접 풀어 φ⁰, φ¹을 구하므로 Tr·Pr 어디서든 보간 오차 없이 계산됩니다. (표 범위: 0.3 ≤ Tr ≤ 4.0, 0.01 ≤ Pr ≤ 10)
압축액체(포화액체 기준): φsat = exp[(B⁰ + ωB¹)·Psatr/Tr], Vsat = Vc·Zc(1−Tr)^0.2857 (Rackett), f = φsat·Psat·exp[Vsat(P − Psat)/RT], R = 83.14 cm³·bar/(mol·K)
Abbott 식은 낮은~중간 압력(대략 Z가 1에 가까운 영역)에서만 유효합니다.
